ADVANCED STRUCTURAL DESIGN

Master structural analysis and design for high-rise towers and concrete structures. Learn lateral load resistance against wind and earthquakes using CSI software (ETABS, SAFE, SAP2000) and both Egyptian Code and ACI standards.

What Will You Learn?

  • • Advanced structural analysis for complex structural systems.
  • • Professional design of slabs, columns, shear walls, and foundations.
  • • Comprehensive study of seismic and wind load effects on buildings.
  • • Using CSI software suite (ETABS, SAFE, SAP2000, CSI Detail, Prokon).
  • • Extracting accurate construction shop drawings and reinforcement details.

Course Curriculum

Deep dive into structural modeling and analysis techniques for different structural layouts using SAP2000 and ETABS.
Practical design procedures for flat slabs, solid slabs, isolated/mat foundations using SAFE and manual checks.
Evaluating lateral forces, dynamic analysis, and checking code limitations for tall structures.
Producing construction-ready reinforcement drawings and verifying design safety.
